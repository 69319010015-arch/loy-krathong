# เว็บแอปพลิเคชัน: โหวตผู้เข้าประกวดและร่วมลอยกระทงออนไลน์ 3D

เว็บแอปพลิเคชัน 3 มิติเสมือนจริงสร้างด้วย **Three.js** จำลองบรรยากาศงานเทศกาลลอยกระทงริมแม่น้ำยามค่ำคืนในวันเพ็ญ รองรับการใช้งานทั้งบน PC, Tablet และ Smartphone

---

## 🌟 จุดเด่นและฟังก์ชันการทำงาน

1. **ฉาก 3 มิติสมจริง (3D Scene with Three.js)**:
   - **แม่น้ำ**: ผิวน้ำเคลื่อนไหวตามระลอกคลื่น พร้อมแสงสะท้อนของดวงจันทร์และแสงเทียน
   - **ดวงจันทร์วันเพ็ญ**: ส่องแสงสีเหลืองนวลลงสู่สายน้ำ
   - **สถาปัตยกรรมไทย**: เรือนไทยริมน้ำ, พระอุโบสถวัด, และพระเจดีย์ยอดทองอร่าม
   - **บรรยากาศงานวัด**: ผู้คนเดินชมงาน 20 คนริมฝั่งน้ำ และโคมลอยประดับท้องฟ้าราตรี
   - **กระทงในแม่น้ำ**: กระทงเริ่มต้น 20 ใบ ลอยกระเพื่อมตามคลื่น พร้อมเปลวเทียนเรืองแสง

2. **การควบคุมมุมกล้อง (Camera Orbit Controls)**:
   - รองรับการหมุนมุมมอง 360 องศา (Drag to Rotate)
   - ซูมเข้า-ออก (Pinch to Zoom บนมือถือ หรือลูกกลิ้งเมาส์บน PC)
   - ปุ่มรีเซ็ตมุมกล้องกลับสู่ตำแหน่งเริ่มต้น

3. **ระบบส่งกระทงเข้าประกวด (Submit Contestant & Krathong)**:
   - **ถ่ายรูปจากกล้องสด (Camera API)** หรือเลือกอัปโหลดไฟล์รูปภาพจากเครื่อง
   - ป้อนชื่อผู้เข้าประกวด และคำอธิษฐาน
   - เลือกรูปแบบกระทง 3 มิติ (ดอกบัวชมพู, ใบตองวิจิตร, ทองคำประกาย)
   - บันทึกและปล่อยกระทงลงสู่สายน้ำแบบเรียลไทม์

4. **ระบบเลือกดูและโหวตกระทง (Interactive Raycasting & Voting)**:
   - แตะหรือคลิกที่ตัวกระทงในแม่น้ำเพื่อเปิดหน้าต่าง Popup
   - แสดงรูปถ่ายเจ้าของกระทง, ชื่อ, คำอธิษฐาน, และคะแนนโหวตปัจจุบัน
   - ปุ่มกดโหวตคะแนน (+1) พร้อมเอฟเฟกต์พลุฉลอง

5. **ตารางสรุปอันดับคะแนน (Leaderboard)**:
   - ดู 3 อันดับแรก (เหรียญทอง, เงิน, ทองแดง) และอันดับคะแนนของผู้เข้าประกวดทั้งหมด

---

## 🚀 วิธีการเปิดใช้งาน (Getting Started)

### การรันเซิร์ฟเวอร์สำหรับการพัฒนา (Development Server)
```bash
npm run dev
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:5173`

### การตรวจสอบเวอร์ชัน Production (Production Preview)
```bash
npm run build
npm run preview
```
